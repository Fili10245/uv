Sobre el curso

Esta experiencia educativa fundamenta las propiedades de los fluidos para el diseño y la operación de equipos de transporte en tuberías, en una y varias fases. El temario oficial se organiza en 6 bloques de saberes, aquí distribuidos en 16 semanas, con énfasis en el balance de energía mecánica, pérdidas por fricción, bombas y compresores, flujo multifásico, redes hidráulicas e introducción a la CFD. Cada semana incluye espacio para notas (.md), PDF, video y código de cálculo en MATLAB y Python.

Semana 5Pérdidas mayores: fricción, Moody y Colebrook

▼ Esta semana está desarrollada por completo como ejemplo del formato.

Video: “Using a Moody Chart”, canal LearnChemE.

$$ h_f = f\,\frac{L}{D}\,\frac{v^2}{2g} \qquad\text{(Darcy-Weisbach)} $$ $$ \frac{1}{\sqrt{f}} = -2\log_{10}\!\left(\frac{\varepsilon/D}{3.7} + \frac{2.51}{Re\sqrt{f}}\right) \quad\text{(Colebrook-White)} $$ 
function f = colebrook(Re, epsD, tol, maxit)
% COLEBROOK  Factor de friccion de Darcy (ecuacion de Colebrook-White).
%   Re    : numero de Reynolds
%   epsD  : rugosidad relativa  eps/D
%   Resuelve la ecuacion implicita por iteracion de punto fijo.
    if nargin < 3, tol = 1e-8; end
    if nargin < 4, maxit = 100; end
    if Re < 2300
        f = 64/Re;                          % regimen laminar
        return;
    end
    f = 0.02;                               % valor inicial
    for k = 1:maxit
        rhs = -2*log10(epsD/3.7 + 2.51/(Re*sqrt(f)));
        f_new = 1/rhs^2;
        if abs(f_new - f) < tol, f = f_new; break; end
        f = f_new;
    end
end

% --- Uso ---
Re = 1e5; epsD = 1e-4;
f = colebrook(Re, epsD);
fprintf('f = %.5f\n', f);                   % ~ 0.018
import math


def colebrook(Re, epsD, tol=1e-8, maxit=100):
    """Factor de friccion de Darcy (Colebrook-White) por iteracion."""
    if Re < 2300:
        return 64 / Re                      # regimen laminar
    f = 0.02                                # valor inicial
    for _ in range(maxit):
        rhs = -2 * math.log10(epsD / 3.7 + 2.51 / (Re * math.sqrt(f)))
        f_new = 1 / rhs**2
        if abs(f_new - f) < tol:
            return f_new
        f = f_new
    return f


if __name__ == "__main__":
    print(f"f = {colebrook(1e5, 1e-4):.5f}")   # ~ 0.018
